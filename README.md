# 📌 Scholarship Compass

Este repositório reúne os materiais desenvolvidos ao longo das oito sprints do **Programa de Bolsas Compass UOL**, contemplando estudos, exercícios, laboratórios e desafios práticos nas áreas de programação, dados e computação em nuvem.

O objetivo deste repositório é concentrar os estudos realizados no programa, servindo como portfólio de aprendizado, além de referência para futuras consultas e evolução profissional na área.

<br>

## Sobre o programa

Durante o programa de bolsas da Compass UOL, aprofundei conceitos fundamentais de desenvolvimento, ciência de dados e arquitetura de dados na nuvem, com foco em soluções modernas utilizando a AWS.

As sprints foram organizadas de forma incremental, partindo de fundamentos de segurança, Git e SQL, avançando para Python, Docker, Spark e, por fim, para um ecossistema completo de dados na AWS, desde ingestão até visualização em dashboards.

## Conteúdo das sprints

- [**Sprint 1**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_1): Segurança da informação, Git/GitHub, Markdown, SQL (DDL, DML, JOINs, funções, subconsultas) e modelagem relacional/dimensional.
- [**Sprint 2**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_2): Python do básico ao avançado, programação orientada a objetos, manipulação de arquivos, NumPy, Pandas e Matplotlib para análise e visualização de dados.
- [**Sprint 3**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_3): Docker (imagens, containers, volumes, Docker Compose), Regex, fundamentos de AWS e desafio de ETL com Python, Pandas, Docker e S3.
- [**Sprint 4**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_4): Trilha de conteúdos AWS (Sales Accreditation, Cloud Economics, Cloud Quest) e desafio com ingestão, limpeza, análise e armazenamento de dados em S3.
- [**Sprint 5**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_5): Apache Spark com PySpark, Amazon Athena e arquitetura serverless de analytics, integrando dados de API (TMDB) via Lambda e S3.
- [**Sprint 6**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_6): Arquitetura moderna de dados na AWS (data lake, data warehouse), Lake Formation, Redshift, AWS Glue, Glue Studio e DataBrew para ETL e camadas de dados.
- [**Sprint 7**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_7): Modelagem dimensional (star schema, snowflake), Data Warehouse e construção da camada Refined com Glue e Spark a partir da Trusted.
- [**Sprint 5**](https://github.com/aline-hoffmann/scholarship-compass/tree/main/Sprint_8): Criação de dashboards e análises visuais no Amazon QuickSight consumindo dados da camada Refined, como análises de filmes com foco em comédia.

## Tecnologias e linguagens utilizadas

- Linguagens: **Python**, SQL, Regex, Markdown. 
- Bibliotecas e ferramentas de dados: Jupyter Notebook, NumPy, Pandas, Matplotlib, Apache Spark, PySpark.
- Controle de versão e colaboração: Git, GitHub.
- Containerização e ambientes: Docker, Docker Compose.
- Serviços AWS: S3, Lambda, Athena, Glue, Glue Studio, DataBrew, Lake Formation, Redshift, QuickSight, além de recursos serverless e de analytics na nuvem.
