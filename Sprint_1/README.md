## SCRUM

No vídeo "Scrum // Dicionário do Programador" identifiquei e conheci novos termos que hoje já estou aplicando na rotina. 

O SCRUM é a metodologia que estamos adotando aqui no Programa de Bolsas. É uma metodologia ágil que organiza o trabalho em ciclos curtos chamados sprints, permitindo que equipes entreguem resultados de forma rápida.
<br>
<br>

## GIT E GITHUB

No curso "Aprenda Git e GitHub em 3 dias + Projetos reais" aprendi a configurar o Git no meu computador e fazer o uso dele.

O Git é um sistema de controle de versão que roda localmente no computador e, com o curso aprendi a utilizar muitos dos seus comandos, como por exemplo o "git init" e o "git push".

Ademais, é importante saber diferenciar o Git do Github. Ao contrário do Git, o Github é uma plataforma online que hospeda repositórios Git na nuvem. Ele permite compartilhar código com outras pessoas, colaborar em equipe, revisar alterações e gerenciar projetos de forma remota.

Com base no curso, criei esse repositório para documentar o Programa de Bolsas.
<br>
<br>

## MARKDOWN

No vídeo "Conhecendo as principais funções do Markdown" aprendi que Markdown é uma linguagem de marcação. É uma forma simples de formatar textos sem precisar de ferramentas complexas. Com ele, é possível criar títulos, listas, links, imagens e destacar palavras em negrito ou itálico de maneira rápida.

O Markdown é muito utilizado em documentações e em arquivos README. Inclusive, foi nesse curso que aprendi a escrever esse e os demais arquivos README do Programa de Bolsas.
<br>
<br>

## SQL

Através do curso "SQL para Análise de Dados: Do básico ao avançado" aprendi desde o básico até técnicas mais avançadas para trabalhar com bancos de dados. 

Esse curso foi imprescindível para a resolução do desafio pois nele aprendi a criar tabelas, selecionar, filtrar e organizar dados, usar funções de agregação como SUM e AVG, fazer junções entre tabelas utilizando os JOINS, criar subconsultas e manipular dados com comandos como INSERT e UPDATE. 

Também aprendi diversos comandos lógicos e de operação e a trabalhar com datas e textos, para analisar dados de forma mais eficiente.

Ademais, compreendi que a modelagem relacional organiza os dados em tabelas normalizadas, reduzindo redundâncias e garantindo consistência. Já a modelagem dimensional estrutura os dados em fatos e dimensões, facilitando a análise e a tomada de decisão.

Ambos os modelos foram exercitados no desafio.
