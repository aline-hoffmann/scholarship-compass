# 📍 **SPRINT 7**

## Modelagem de dados para Data Warehouse

O curso de Modelagem de dados para Data Warehouse trouxe uma revisão aprofundada de conceitos apresentados nas primeiras sprints. Foram abordados os métodos de modelagem de dados mais utilizados em ambientes de Data Warehouse, como o star schema e o snowflake, detalhando as diferenças entre eles e suas aplicações práticas.

Além disso, o curso explorou a definição e os objetivos de um Data Warehouse, diferenciando sua arquitetura de soluções como Data Lakes, e mostrando como elas podem ser integradas dentro de estratégias modernas de gerenciamento de dados.

## Amazon Q Developer for Programmers and DevOps AWS AI coding

O segundo curso da Sprint trouxe uma abordagem prática sobre o assistente de inteligência artificial da Amazon, dedicado a facilitar a rotina de programadores e equipes de DevOps. 

Aprendi como a ferramenta pode agilizar o desenvolvimento de aplicações na nuvem, sugerindo trechos de código, corrigindo erros e automatizando testes. 

O curso demonstrou que o Amazon Q Developer vai além de recursos básicos, fornecendo orientações para escrita de código mais eficiente e organizado, otimizando o fluxo de trabalho dentro das soluções AWS.

## DESAFIO

O desafio da Sprint 7 correspondia à quarta etapa do desafio final, focando na construção da camada Refined. Nesta fase, trabalhei no processamento e organização dos dados modelados para análise, usando o AWS Glue em conjunto com Apache Spark para ler os dados confiáveis da Trusted, aplicar a modelagem multidimensional e salvar os resultados em formato Parquet na camada Refined.
